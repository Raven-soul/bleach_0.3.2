Особая таблица созданная для соединения контента страницы с галереей изображений. 

Логика такая:
Для каждой страницы создается свой пул картинок, можно сказать что это альбом. Страница (классы, расы ..) имеет ссылку на этот альбом картинок.
Далее используется таблица [[cnt_gallery_content]] для получения картинок одного альбома. После чего данные альбома выводятся на странице перед пользователем.
