Таблица формирует главное меню классов. Тут содержатся данные каждого поля меню отдельно.

**name** - Название вкладки класса

**latin_name** - английское название класса, выводится в поле меню под русским.

**logo** - ссылка на картинку.

**link** - ссылка на страницу сайта

**group_id** - ссылка на таблицу [[cnt_class_menu_group]]
