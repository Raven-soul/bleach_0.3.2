Тут все просто. Таблица служит соединением альбома и картинок. Плюс указывает очередность картинок, если это требуется и определяет нужно ли картинку скрыть.

Ссылается на [[cnt_content_gallery]] для соединения с данными альбома
Ссылается на [[cnt_gallery_archive]] для получения данных картинки

**order_num** - колонка, определяющая очередность. Но может быть и null, в таком случае очередность определяет **id**

**show** - колонка, определяет нужно ли показать/скрыть картинку с сайта без ее удаления из базы
