Тип информационного блока на странице. Необходим для определения специфики отрисовки элемента на странице. В разных типах идет разный сбор данных.
На данный момент на сайте есть только три типа блока информации:

- Блок данных - обычный блок данных, содержит в себе:
	- Заголовок - название блока;
	- Требования - часто это либо уровень, либо определенный уровень конкретной характеристики, либо владение определенным навыком. Имеет вариант остаться пустым;
	- Информация - тело информационного блока, содержит данные, которые требуется показать пользователю. Это либо навыки, либо заклинания, либо еще что то

- Синий блок - информационный блок с особенным оформлением. В основном заключается в синей рамочке и немного измененных шрифтах данных внутри. Чаще всего содержит:
	- Информацию о здоровье бойца, спасброски и т.д. 

- Спойлер блок - особый информационный блок, который в стартовом положении свернут, а при разворачивании показывает дополнительную информацию пользователю. Отличительной чертой от остальных спойлеров является то, что он может быть вызван в информационном теле страницы. То есть среди остальных обычных инфо блоков. (Обычные спойлеры располагаются после информационного тела страницы в секции спойлеров).
