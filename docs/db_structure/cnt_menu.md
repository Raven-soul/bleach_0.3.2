Таблица для работы главного меню сайта. 

**group_id** - Ссылка на таблицу [[cnt_menu_group]]. Все поля в рамках одной группы будут визуально отделены от других групп. Иначе назвать можно Секцией

**name** - название поля меню. Оно будет отображаться на странице.

**link** - ссылка на страницу сайта.

**logo** - название логотипа для вкладки меню

**show** - определяет нужно ли отображать данную строку меню
